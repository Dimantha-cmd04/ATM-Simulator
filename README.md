# 🏧 ATM Simulator

A simple **console-based ATM Simulator** developed using **Java**. This project demonstrates basic banking operations while practicing **Object-Oriented Programming (OOP)**, `ArrayList`, methods, loops, and exception handling.

## ✨ Features

* 🔐 PIN-based login
* 💰 Check account balance
* 💵 Deposit money
* 💸 Withdraw money
* 🔄 Transfer money
* 🔑 Change PIN
* 📋 View transaction history
* ⚠️ Input validation and exception handling
* 🔒 Maximum 3 login attempts

## 🛠️ Technologies Used

* Java
* Object-Oriented Programming (OOP)
* ArrayList
* Exception Handling
* Java Date & Time API
* IntelliJ IDEA

## 📌 Class Description

### `Account.java`

Manages account information such as:

* Account number
* PIN
* Balance
* Deposit
* Withdrawal
* PIN change

### `ATM.java`

Controls the main ATM operations and user menu.

### `Transaction.java`

Stores transaction type, amount, and date/time.

### `Main.java`

The starting point of the application.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in **IntelliJ IDEA**.
3. Make sure all Java files are inside the same source folder.
4. Open `Main.java`.
5. Click **Run**.
